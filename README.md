## ✈️ About the Project

**Roamora** is a premium travel agency concept focused on curated journeys across India.

The website is intentionally built as a **single-page experience**. Instead of opening separate HTML pages, the navbar smoothly takes visitors to the relevant section of the same page.

The visual direction uses an editorial travel aesthetic with restrained typography, spacious layouts, destination photography and a muted premium palette.

## 🧭 What's Inside

| Section | Details |
|---|---|
| 🏠 Home | Hero section, brand introduction and CTA |
| 🗺️ Destinations | **24 travel destinations** across India |
| 🧳 Packages | **8 curated travel packages** |
| 🌿 Experiences | Slow travel, food, nature, heritage and more |

| 📩 Contact | Travel enquiry form and contact details |

## 🎨 Design Direction

- Editorial travel-agency aesthetic
- Serif display typography paired with clean sans-serif UI text
- Neutral, earthy colour palette
- Large destination imagery
- Minimal borders and controlled spacing
- Subtle hover interactions
- Clear CTAs and navigation
- Responsive layouts for desktop, tablet and mobile
- No unnecessary animations or decorative UI clutter

## 🚀 Run Locally

Clone the repository and open `index.html`.

```bash
git clone YOUR_REPOSITORY_URL
cd roamora-single-page
```

You can also open the project directly with **VS Code Live Server**.
