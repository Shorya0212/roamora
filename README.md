# Roamora Travel Website

A premium single-page travel and tourism website built with semantic HTML5 and CSS3.

## Features

- Single-page layout with anchor navigation
- 24 destinations
- 8 travel packages
- Responsive desktop, tablet and mobile design
- Destination cards and package sections
- Experiences section
- About section
- Enquiry form
- Semantic HTML5 structure
- Flexbox and CSS Grid
- No framework required

## Structure

```text
roamora-single-page/
├── index.html
├── css/
│   └── style.css
├── images/
│   └── README.md
└── README.md
```

## Run

Open `index.html` directly in a browser or use VS Code Live Server.

## Deployment

The project can be deployed as a static website using GitHub Pages, Netlify or Vercel.
